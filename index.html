03 / architecture

The Sync Engine

How the system works under the hood.

  1. 01 / Capture

    A background service worker runs periodic checks via chrome.alarms every minute, verifying if the active tab matches an explicit allowlist (cs50.harvard.edu, MIT OCW, OMB+). A telemetry heartbeat triggers only during active study sessions.

  2. 02 / Ingestion

    The Flask endpoint /api/save verifies the API authentication key in the request header. It parses the URL and page title, classifies the category (cs50, math), and sanitizes payloads before writing to the database.

  3. 03 / Persistence

    Every validated focus minute is committed as an immutable record in a PostgreSQL instance on Heroku—including Unix timestamp and category tags, ensuring persistence across reboots.

  4. 04 / Visualization

    frontend.js polls /api/get every 30 seconds, asynchronously updating counters and live status indicators without page reloads. Displayed metrics are always accurate within a 30-second window.
